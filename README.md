# Campo Data T2

Crea una página llamada "campo data" donde se vea un mapa de Argentina dividido por provincias y donde cuando hagas click en una provincia muestre datos como:cultivo más recomendado, cultivo más cosechado, costo promedio de cada cultivo(en dólares y en pesos argentinos) y el clima promedio de la región
